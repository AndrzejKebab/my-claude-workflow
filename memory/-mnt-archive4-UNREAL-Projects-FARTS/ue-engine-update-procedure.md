Bumping the source build at `/mnt/archive4/UNREAL/UE_5.8.0` to a new tag. Driver script from the 5.8.0→5.8.1 run: `/mnt/archive4/UNREAL/ue581_update.sh` (resumable, stage-logged to `ue581_update.log`) — copy and retarget it rather than starting over.

**Sequence:** discard local engine edits → `git fetch --depth 1 --no-tags origin refs/tags/<tag>:refs/tags/<tag>` (the clone is **shallow**, 33G `.git`) → checkout → `Setup.sh` → `GenerateProjectFiles.sh` → `make` → project rebuild → re-inject Voxel hooks → validate. On a 24-core box the whole engine leg took **66 minutes**, not the 2–3h I guessed; the project rebuild was 3 minutes.

**Traps, all hit for real:**

- **`git diff` here emits a decorated, non-unified format.** Saving it as a backup patch produces something `git apply` rejects with "No valid patches in input". Use `git diff --no-ext-diff`, or better, don't hand-preserve the Voxel shader hooks at all (below).
- **Voxel engine shader hooks** (the `BEGIN VOXEL SHADER HOOK <guid>` blocks in 5 `.ush` files under `Engine/Shaders/Private/`) are the plugin's autogenerated code. Discard them before checkout, then re-inject after the project build with `UnrealEditor-Cmd <abs-proj>.uproject -run=ApplyVoxelShaderHooks -unattended -nopause -stdout`. It regenerates against the *new* engine's sources rather than force-fitting old context lines. Restored all 8 blocks / 152 lines cleanly.
- **`-run=` commandlets need an ABSOLUTE `.uproject` path** — a relative one fails with "Failed to open descriptor file" and a fatal at LaunchEngineLoop.cpp:2567.
- **Commandlets exit 1 whenever any error was logged**, even a benign pre-existing one (the `GameFeatureData` asset-manager complaint fires every run). Exit code is not the verdict — check the actual artifact: the `.ush` files for hook blocks, `Saved/FartsCharacterValidation.json` for `passed: true`. `validate_farts_character.py` prints `[FARTS-TEST] PASS` on the *LogPython: Error* channel, so it exits 1 on success.
- `Setup.sh` finishing in ~7s is **not** a no-op — 5.8.0→5.8.1 changed only 304 of 134,332 dependency files. Verify by hashing the changed entries against `Engine/Build/Commit.gitdeps.xml` rather than trusting or distrusting the runtime.
- Untracked engine content (`Engine/Plugins/Marketplace/*`, `.mcp.json`) survives a tag checkout — no need to protect it.

See [[farts-ue58-buildid-mismatch]] for the post-rebuild BuildId handling, which is the part most likely to silently break plugins.
