When the user asks a question about something I wrote ("why would that be a BAD_REQUEST?", "is
TS-01 even real?"), they already know the answer. The question is a report that **the writing begs
it**. Fix the document so it no longer does; keep the reply to what changed.

**Why:** stated directly — *"dont answer me these questions directly - i know the answer. the reason
i'm sending you these questions is because your writing BEGS for these questions and then you
correct the writing so it no longer BEGS that question."*

**How to apply:** treat the question as a defect report against the prose, not a request for
information. Put the answer in the file. In the reply, say what moved and why, not the explanation
itself. Their register for the fix: explicit, almost verbose, technical, but never obvious — name
the symbol, the line, the status, the mechanism.
