Avoid dualistic contrast constructions in prose: "it is X, not Y", "X — never Y" as rhetoric, "A, not B" appositives. The user reads them as pretension and classic LLM-speak.

**Why:** the pattern substitutes rhetorical contrast for direct statement; in canon docs it also trains future agents to reproduce the tic.

**How to apply:** state the fact or rule directly. Keep a contrast only when two cases genuinely need distinguishing (two inputs, two outcomes). Plain prohibitions ("do not X") stay plain. Applies to chat, commit messages, docs, skill/agent definitions. Encoded in hypertino `AGENTS.md` style canon; related: [[anti-ceremony-writing]].
