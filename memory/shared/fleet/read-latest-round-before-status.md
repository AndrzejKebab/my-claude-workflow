# Before writing what a PR still owes, read its latest review round; do not restate an older status

Symptom: You are writing a label reason or a Waiting line that says what the author is still doing
Domain: fleet
Verified: 2026-11-10 at 74861ec7

## What to do

Open the newest Reviewer round and the newest author comment, and name only the items they leave open. A wrong 'still owes' line sends the author to redo finished work and hides the real next step.

## Evidence

PR #431 2026-11-06 Manager label note: 'Worker-3 is still writing the Auto-warning collector' - it had landed at 74861ec7 and Reviewer round 2 closed it; the only open item was the a16 main merge (Advisor, issuecomment-6755552514)
