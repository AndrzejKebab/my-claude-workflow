# PROSE — how output gets written (binding)

Governs everything written for the user: chat replies, specs, commit messages, doc prose, code comments. [[NONDUAL.md]] governs the reasoning; this file governs the sentence that reasoning comes out in. They connect — a frame that the analysis rejected can still be smuggled back in by grammar.

## The two-clause tic

The failure: writing a sentence whose *shape* demands a second clause, then filling that slot with whatever completes the pattern instead of with what is true.

Shapes that do it: `X, never Y` · `Not X. Only Y.` · `A rather than B` · `It isn't X — it's Y` · rule-of-three negations (`no X, no Y, no Z`).

Why this is dangerous rather than merely mannered: the construction builds a two-pole frame *before* there is content for the second pole, and the empty pole pulls. Whatever arrives to fill it was generated by cadence, so it reads confident and parallel while never having been checked. It is the defect [[NONDUAL.md]] names at the reasoning level, arriving through syntax — which is exactly how it evades a reasoning-level guard.

Worked example (2026-07-27, vegetation spec):

> CPU never sees an instance. It only decides which tiles are visible.

First clause true. Second invented to complete `never X … only Y`, and wrong: `VTClipmapSpanner` has the CPU choosing *residency*, while *visibility* is decided GPU-side in `HeightfieldOcclusionCull.compute`. Two different decisions collapsed into one word, and the wrong one got handed over. Sweeping that same page found three more: an overclaimed "the only source that…", a "store nothing" that stored something, and a "deliberately, not by drift" carrying no content at all.

How to apply:

1. Write the clause that is true.
2. Interrogate any second clause: is it here because something is there, or because the shape left a hole?
3. Empty hole — stop. One clause is a complete sentence.
4. Real fork — keep both poles, and make each independently checkable.

## Contrast is not banned

Do not pole-flip into never writing a two-clause sentence; that is [[NONDUAL.md]]'s overcorrection failure and it costs real precision. Contrast earns its place when the fork exists in the territory and both sides are load-bearing:

> Storage scales with map area, not plant count.

Both scalings are genuine candidates, choosing between them *is* the design decision, and either side survives being checked alone. Keep it. The defect is dose and origin, not direction.

## Verification duty

Any clause asserting how the code behaves is a claim, and cadence-generated clauses are precisely the ones nothing forced against the source. Confirm before shipping. Note that `only`, `never`, and `all` are universal quantifiers: asserting one is asserting a search was done. Do the search or weaken the word. Same instinct [[VERIFY.md]] applies to gates.

## Related tics

- **Manufactured stakes** — "this is the whole reason it works", "that is the hard part". Keep only where the emphasis is earned and specific.
- **Superlatives without a named set** — "the only source". Name the set it ranges over, or drop it.
- **Em-dash asides that restate the clause they hang off**, adding rhythm and no information.
- **Hedging adverbs carrying nothing**: perhaps, might, could possibly.
